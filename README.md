# OpenZync organization files

Community health files GitHub applies to every repository in the
[openzync](https://github.com/openzync) organization that does not define its own: security policy,
code of conduct, contribution guide, support guide, and issue templates. They live at this
repository's root; issue templates live in `.github/ISSUE_TEMPLATE/`, the path GitHub reads.

The organization profile at [github.com/openzync](https://github.com/openzync) is
[`profile/README.md`](./profile/README.md), with its images in `profile/assets/`.
